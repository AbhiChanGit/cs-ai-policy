Token usage

Parsed by src/tokens.py from Claude Code's own transcript files (~/.claude/projects/…/*.jsonl), one record per API call, de-duplicated by message id. Calls are assigned to the phase of the next PROGRESS.md entry.

How to read this. Every call re-sends the whole conversation. Most of it comes from the prompt cache (cache read), which is cheap but still counts toward plan limits. So the cost of a step depends less on the step and more on how long the conversation already is. That is exactly what /clear (start fresh, rely on SPEC.md) and /compact (summarize history) attack.

Context size per call

Context = input + cache write + cache read for one call. Vertical lines mark phase changes. A /clear would drop the line back to the baseline at each phase.
